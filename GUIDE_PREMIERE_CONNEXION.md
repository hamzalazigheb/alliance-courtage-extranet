## Procédure pour l'administrateur

### Création d'un nouvel utilisateur

1. Se connecter à l'interface d'administration
2. Accéder à "Gestion des utilisateurs"
3. Cliquer sur "Créer un utilisateur"
4. Remplir les informations :
   - Email (obligatoire)
   - Nom (obligatoire)
   - Prénom (obligatoire)
   - Dénomination sociale (nom du cabinet)
   - Téléphone
   - Code postal
   - Date de validité du compte
5. Générer un mot de passe temporaire
6. Enregistrer l'utilisateur
7. **Envoyer le message de bienvenue** avec les identifiants au nouvel utilisateur

### Génération du mot de passe temporaire

Le mot de passe temporaire doit :
- Être aléatoire et sécurisé
- Contenir au moins 12 caractères
- Inclure des majuscules, minuscules, chiffres et caractères spéciaux
- Être communiqué de manière sécurisée (email sécurisé ou appel téléphonique)

### Réinitialisation de mot de passe

#### Si l'utilisateur demande une réinitialisation :

1. L'utilisateur clique sur "Mot de passe oublié ?" sur la page de connexion
2. Une demande est créée dans "Gestion des demandes de réinitialisation"
3. L'administrateur voit la demande en attente
4. L'administrateur génère un nouveau mot de passe
5. Le système envoie automatiquement un email à l'utilisateur avec le nouveau mot de passe
6. L'utilisateur se connecte avec le nouveau mot de passe et le change

#### Si l'administrateur doit réinitialiser :

1. Accéder à "Gestion des utilisateurs"
2. Trouver l'utilisateur concerné
3. Cliquer sur "Réinitialiser le mot de passe"
4. Générer un nouveau mot de passe temporaire
5. Communiquer le mot de passe à l'utilisateur de manière sécurisée
6. Demander à l'utilisateur de le changer dès la connexion

## FAQ - Foire aux questions

### Pour les utilisateurs

**Q: Je n'ai pas reçu mes identifiants, que faire ?**
R: Vérifiez vos spams. Si vous ne trouvez pas l'email, contactez l'administrateur à admin@alliance-courtage.fr

**Q: Mon mot de passe ne fonctionne pas**
R: Assurez-vous de :
- Respecter les majuscules/minuscules
- Ne pas avoir d'espaces avant ou après le mot de passe
- Utiliser le dernier mot de passe reçu

**Q: Je ne peux pas me connecter, mon compte est inactif**
R: Contactez l'administrateur pour réactiver votre compte

**Q: Combien de temps mon mot de passe temporaire est-il valide ?**
R: Le mot de passe temporaire n'expire pas, mais vous devez le changer dès votre première connexion pour des raisons de sécurité

**Q: Que faire si j'oublie mon nouveau mot de passe ?**
R: Utilisez la fonction "Mot de passe oublié ?" sur la page de connexion. L'administrateur traitera votre demande rapidement.

### Pour les administrateurs

**Q: Comment savoir si un utilisateur s'est connecté pour la première fois ?**
R: Consultez l'historique des connexions dans "Gestion des utilisateurs"

**Q: Un utilisateur n'a pas reçu l'email de bienvenue**
R: Vérifiez que l'adresse email est correcte dans le profil utilisateur et renvoyez l'email manuellement

**Q: Combien de demandes de réinitialisation un utilisateur peut-il faire ?**
R: Il n'y a pas de limite, mais seule la dernière demande est valide

**Q: Comment désactiver temporairement un compte ?**
R: Dans "Gestion des utilisateurs", décochez la case "Compte actif" pour l'utilisateur concerné

## Bonnes pratiques

### Pour les utilisateurs

1. **Première connexion** : Changez immédiatement votre mot de passe temporaire
2. **Mot de passe fort** : Utilisez une phrase de passe ou un gestionnaire de mots de passe
3. **Sécurité** : Ne partagez jamais vos identifiants
4. **Déconnexion** : Déconnectez-vous toujours après chaque session
5. **Mise à jour** : Gardez vos informations de profil à jour

### Pour les administrateurs

1. **Communication claire** : Expliquez clairement la procédure de première connexion
2. **Suivi** : Vérifiez que les nouveaux utilisateurs se connectent dans les premiers jours
3. **Support** : Soyez disponible pour aider les utilisateurs en difficulté
4. **Sécurité** : Ne communiquez jamais de mots de passe par SMS ou canaux non sécurisés
5. **Documentation** : Gardez une trace des comptes créés et des réinitialisations
